# Ping Pong Game (Python Turtle)

## Overview

This project is a classic two-player Ping Pong game developed using Python's built-in `turtle` graphics library. The game provides an interactive graphical interface where two players control paddles to bounce a ball and score points.

## Features

* Two-player gameplay
* Real-time ball movement
* Score tracking system
* Keyboard controls for both players
* Collision detection for paddles and boundaries
* Simple and colorful GUI using Turtle

## Technologies Used

* Python 3
* Turtle Graphics Library

## Controls

| Player       | Move Up        | Move Down        |
| ------------ | -------------- | ---------------- |
| Left Player  | `R`            | `C`              |
| Right Player | `↑` (Up Arrow) | `↓` (Down Arrow) |

## How to Run

1. Install Python (3.x).
2. Clone the repository:

```bash
git clone https://github.com/your-username/ping-pong-game.git
```

3. Navigate to the project directory:

```bash
cd ping-pong-game
```

4. Run the Python file:

```bash
python Game.py
```

## Game Mechanics

* The ball bounces off the top and bottom walls.
* Players earn a point when the opponent misses the ball.
* Scores are displayed at the top of the screen.
* The game continues indefinitely until manually closed.
